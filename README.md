# 🚀 Astro Language Framework

> **Astro** — это декларативный компилируемый фреймворк для создания реактивных React-компонентов через удобный JSON/JSX синтаксис.

## 🌟 Особенности

* **Декларативная структура**: Описание состояния (`state`), пропсов (`props`) и методов в чистом формате данных.
* **React JSX под капотом**: Родной JSX-рендеринг без необходимости писать громоздкие классы или длинные React-хуки вручную.
* **Автоматическая реактивность**: Мощный транспилятор на Python, который автоматически оборачивает мутации состояния в `useState` и `useEffect`.
* **Удобный CLI**: Компиляция `.astro` или `.ast` файлов одной простой командой прямо из терминала.

## 📁 Структура проекта

```text
astro/
├── ast_nodes.py      # Классы AST (Абстрактного синтаксического дерева)
├── lexer.py          # Лексический анализатор (Токенизатор)
├── parser.py         # Синтаксический анализатор (Парсер)
├── codegen.py        # Генератор кода (Astro -> React JS)
├── cli.py            # Основная точка входа компилятора (Python)
├── cli.js            # Node.js CLI-обертка для запуска
├── package.json      # Конфигурация npm пакета
└── examples/
    └── hello.astro   # Примеры компонентов

```

## 🚀 Быстрый старт

### 1. Установка и связывание CLI

Склонируйте репозиторий и зарегистрируйте глобальную команду `astro`:

```bash
git clone [https://github.com/your-username/astro.git](https://github.com/your-username/astro.git)
cd astro
npm link

```

> **Примечание**: Убедитесь, что в вашей системе установлен **Python 3.10+** и **Node.js**.

---

### 2. Создание первого компонента (`hello.astro`)

Создайте файл `hello.astro` со следующим содержимым:

```astro
{
  "component": "HelloWorld",
  "props": {
    "name": "Мир"
  },
  "state": {
    "message": "Привет из Astro!"
  },
  "render": (
    <div className="hello-container">
      <h1>{state.message}</h1>
      <p>Добро пожаловать, {props.name}!</p>
    </div>
  )
}

```

---

### 3. Компиляция в React

Запустите сборку с помощью Astro CLI:

```bash
astro hello.astro
```

Компилятор сгенерирует готовый React-компонент **`hello.js`**:

```javascript
// Auto-generated by Astro Language Compiler
import React, { useState, useEffect } from 'react';

function HelloWorld(props) {
  const defaultProps = {"name": "Мир"};
  const finalProps = { ...defaultProps, ...props };

  // --- Reactive States ---
  const [message, set_message] = React.useState("Привет из Astro!");

  // --- JSX Layout ---
  return (
    <div className="hello-container">
      <h1>{message}</h1>
      <p>Добро пожаловать, {finalProps.name}!</p>
    </div>
  );
}

export default HelloWorld;

```

## 🛠 Вызов команд CLI

| Команда | Описание |
| --- | --- |
| `astro <filename>` | Компилирует файл и создает `.js` рядом |
| `astro <filename> -o build.js` | Компилирует файл с указанием конкретного имени на выходе |
| `astro --help` | Выводит справку по использованию |

## ⚡ Как это работает

1. **Lexer (`lexer.py`)**: Разбивает исходный `.astro` файл на цепочку токенов, выделяя скобки, строки, ключевые слова и JSX-блоки.
2. **Parser (`parser.py`)**: Собирает токены в AST (дерево абстрактного синтаксиса).
3. **Code Generator (`codegen.py`)**: Преобразует AST в оптимизированный и валидный ES6 JSX-код React.
